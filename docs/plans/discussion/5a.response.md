Your radio idea is nearly right, but it conflicts with the earlier requirement that one ingredient may retain both a volume and a weight. I would keep both measurements possible and make the entry control compact rather than choosing only one category for the whole row.

Use this column order:

| Main | Ingredient | Quantity | Unit | Preparation |
| --- | --- | --- | --- | --- |

The **Quantity + Unit** cells behave as one measurement editor:

- `Quantity`: numeric input, such as `1`, `2–3`, or `1 1/2`.
- `Unit type`: a small segmented control: **Volume**, **Weight**, or **Count**.
- `Unit`: a searchable combobox filtered to that type.
- `Preparation`: diced, melted, divided, chilled, etc.
- An `+ Add measurement` icon adds the other convertible measurement, so a row can become `1 cup / 254 g`.

“Count” is better than “amount.” It covers `1 cucumber`, `2 cloves`, `1 can`, `3 sheets`, and `1 package` without implying a standard convertible unit.

The picklists should work like this:

- **Weight:** predefined, non-editable recognized units: grams, kilograms, ounces, pounds, etc.
- **Volume:** also predefined, non-editable recognized units: teaspoons, tablespoons, cups, pints, liters, etc. Users should not add units here, because conversion needs a known definition.
- **Count:** user-managed picklist: clove, cucumber, can, package, bunch, sheet, sprig, pinch, and so on.

So there is never a huge all-units dropdown. The user first chooses a category, then sees only the relevant choices.

For exceptional wording, add a small optional field named **Descriptor** or **Specification** after Unit, rather than “amount note.” Examples:

- `1` + `can` + `14 oz`
- `2–3` + `cloves` + `large`
- blank + `to taste`
- `1` + `cup` + `about`

I prefer **Specification**: it conveys “the detail that qualifies this measurement,” without sounding like a generic note. It should not be a picklist because these details are too varied.

The normal recipe-card view still stays elegant:

- `1 cup / 254 g all-purpose flour`
- `2–3 large cloves garlic, minced`
- `salt, to taste`
- `1 14 oz can coconut milk`
