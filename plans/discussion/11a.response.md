## What changed

1. **Skip email verification.** The skip option is gone. Production requires email verification, and local development turns it off. Because this is now a per-environment setting, the app-managed verification I proposed earlier is no longer needed.
2. **Admin.** Admin is an account flag that existing admins can grant. The first production account is an admin by default.
3. **Local first.**
   - Slice 0 is now a local setup: one command starts the app and a local Supabase stack, one command runs the tests, and the README covers local setup. It needs Docker and the Supabase CLI.
   - Google sign-in is no longer in slice 2.
   - A new slice 25, "Go online", comes last. It covers the Supabase, Vercel and Google setup, email delivery, production switches and a step-by-step README. It also restores a database exported locally into production and checks things that need HTTPS on a real phone, such as install and wake lock.
4. **Backups.** The ZIP export is now documented as the only backup. A full-database import must therefore rebuild the account completely.
5. **Seeding.** Yes, every picklist is seeded from the documented examples, in the listed order. They are editable and reorderable in Settings.
